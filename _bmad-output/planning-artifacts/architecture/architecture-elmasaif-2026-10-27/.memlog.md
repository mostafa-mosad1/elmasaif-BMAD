- (decision) AD-1 Monorepo layout: apps/web (Next.js 15 App Router), apps/api (NestJS), packages/shared (types, Zod, constants), orchestrated via npm workspaces
- (decision) AD-2 Strict presentation/domain separation: Next.js is presentation-only with no direct DB access or server mutations; all business rules and state machines live in NestJS REST API
- (decision) AD-3 Dual bank transfer financial model: Platform never holds multi-million SAR purchase funds; Buyer wires purchase price to Seller verified IBAN and platform commission (2.5%) to Platform IBAN with reference code ELM-xxx-C; Admin audits both proofs
- (decision) AD-4 Prisma interactive transactions & locking: Deal creation and final completion run inside Prisma transactions with row locks on listing and partial unique index ensuring at most one active non-terminal deal per listing
- (decision) AD-5 Separate authentication realms: End users and Admin back-office operate separate database tables, session cookies (HttpOnly, Secure, SameSite=Lax), and guards; Argon2id password hashing; OTP provider abstraction with static dev provider (123456)
- (decision) AD-6 S3-compatible private object storage with time-limited signed URLs (max 10MB, PDF/images), audit logging insert-only service inside Prisma transaction, and PostgreSQL background queue for cron jobs
- (event) architecture spine finalized
- (decision) AD-1 amended: Next.js version = latest stable (verified at implementation); /api proxied through Next.js rewrites so session cookies stay same-origin
- (decision) AD-3 amended: Remove hardcoded 2.5%; Commission = rate % + fixed amount from system settings (UC-76), snapshotted on Deal at final approval (UC-70B); snapshot seller payout account (holder name + IBAN) on Deal; configurable 48h payment deadline with timeout job; dispute status suspends timer
- (decision) AD-4 amended: SELECT ... FOR UPDATE executed via inside Prisma interactive transaction; partial unique index and CHECK constraints created in raw SQL migration
- (decision) AD-5 amended: Hard production guard for static OTP provider; application startup check actively fails and crashes boot if static OTP is enabled in NODE_ENV=production
- (decision) Realtime resolved: Short polling (15-30 s) adopted for MVP negotiation and status updates; SSE deferred to post-MVP
- (decision) AD-7 Background jobs: pg-boss queue runner embedded inside API process, @nestjs/schedule for cron; all job handlers idempotent; audit events emitted on state changes; separate worker process deferred to scale
- (decision) AD-8 API conventions & mutations: Explicit action endpoints (no free PATCH status); standard error format { code, message, details, requestId }; Idempotency-Key required on proof uploads, final approval, and payment decisions; optimistic locking via version + If-Match header returning 409 Conflict
- (decision) Contracts and client tooling: No generated OpenAPI client in MVP; share Zod schemas and TypeScript types directly via packages/shared; SMS provider and map provider remain deferred
- (event) architecture spine updated and finalized with AD-1 through AD-8
